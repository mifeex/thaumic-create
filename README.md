# Thaumic Create — NeoForge 1.21.1

Ветка `neoforge/v1.21.1` содержит только аддон для Minecraft 1.21.1.

| Ветка | Версия |
|---|---|
| `main` | Forge 1.20.1 |
| `neoforge/v1.21.1` | NeoForge 1.21.1 |

Исходники находятся в `src/main/java`, ресурсы — в `src/main/resources`.
Каждая ветка собирается самостоятельно из корня репозитория.

## Сборка

Требуется JDK 21.

```sh
./gradlew build
```

При заполненном кэше Gradle: `./gradlew --offline build`.
Результат: `build/libs/thaumic-create-neoforge-1.21.1-0.5.0.jar`.
`python3 tools/build.py` собирает только текущую ветку.

В `libs/` нужны compile-only JAR Create 6.0.10, TR API 2.0.9
и вложенные библиотеки Create (Ponder, Registrate, Flywheel).
Используются зависимости NeoForge 1.21.1.
Локально зависимости подготовлены. В Git они не включены; при свежем клонировании
их нужно предоставить отдельно. Они не упаковываются в JAR аддона.

## Содержимое 0.4.0

- Покупаемые исследования диорита, андезита и гранита, латунь с головоломкой.
- Прессование таумита и теневого металла; покупка исследований обязательна для игрока, положившего слиток.
- Двунаправленный переходник труб TR ↔ Create: направление задаёт помпа.
- Одноаспектный бак: 64 единицы на блок, 256 на 2×2×1, 2560 на 2×2×10.
- Двухблочный двигатель Potentia: 1–128 RPM, старт 8 RPM, расход каждые 40 тиков.

Двигатель открывается после латуни и таумитовой пластины. В центре инфузии латунный
корпус; вокруг 2 таумитовые пластины, 4 латунных листа, 2 блока магического дерева
и большая шестерня. Эссенция: 32 Potentia, 16 Machina, 16 Motus, 8 Permutatio,
8 Ordo. Нестабильность 6. Якоря головоломки пользователь настроит редактором TR.

Расход Potentia за 40 тиков: 1–7 RPM → 0,25; 8–16 → 0,5; 17–32 → 1;
33–64 → 2; 65–96 → 4; 97–128 → 8. Учёт в четвертях единицы.
Удержание ПКМ открывает настройку Create. Шестерня модели вращается вместе с выходным валом;
визуальная проверка в обычном клиенте остаётся ручной. Временная мощность — 16 SU/RPM.
Перед разборкой освободите устройства от эссенции; содержимое не переносится в предмет.

Исходная модель двигателя: `assets-src/essentia_engine.bbmodel`.
Материалы ключа сохранены в `create-wrench/`.

## Проверки

Серверные GameTest до перестройки: 9/9, включая двигатель.
Команда: `./gradlew --offline -PverifyPress runPressGameTest`.
Тестовые зависимости должны быть подготовлены в `build/validation-mods` и `build/validation-compile`.
Тестовые классы находятся в `src/validation` и исключены из релизного JAR.
Сохранённые логи — в `docs/validation/`.

При переходе со старого KubeJS-полуаддона отключите перенесённые определения
камней, латуни и общей вкладки. ID самих исследований сохранены для совместимости прогресса.

Локально ветка автоматически использует зависимости из .gradle/local-libs/neoforge-1.21.1.
Переключение веток не требует ручной замены библиотек. Для свежего клона используется libs/.

## Запуск клиента

```sh
./gradlew runClient
```

Папка клиента — `run-neoforge/` (миры Forge из `run/` не затрагиваются).
Create и библиотеки берутся из каталога compile-only зависимостей.
Thaumic Reborn, его API и Curios — из `.gradle/local-runtime/neoforge-1.21.1`
либо `runtime-mods/` при свежем клонировании. В текущем рабочем каталоге
все runtime-зависимости подготовлены. Они не упаковываются в аддон.

Исправление двигателя: тяга Potentia повышена до 128, чтобы забирать эссенцию
через трубы из обычных и помеченных банок (тяга 32/64). Верхний ротор
отрисовывается отдельно и использует действительную скорость сети Create.

Шестерня двигателя передаёт вращение зубьями. Малая шестерня Create сверху
ставится с параллельной осью и вращается в обратную сторону (1:1).
Большая шестерня сверху ставится с перпендикулярной горизонтальной осью,
как на регуляторе скорости Create, и получает заданные RPM (1:1).
Форма выделения и коллизия повторяют корпус, опоры и рабочую область шестерни.
При удержании шестерни Create помощник показывает место установки и выбирает ось
зацепления. Обычная установка рядом также ориентирует шестерню; Shift оставляет
ручной выбор оси.
Двигатель не объявляет боковые выходы вала.

Данные аддона находятся в src/main/resources/data/thaumic_create/arcana.
Каталог data/kubejs удалён; рецепты тигля используют ID thaumic_create:brass,
thaumic_create:create_diorite, thaumic_create:create_andesite и thaumic_create:create_granite.
ID исследований и сохранённая расстановка узлов сохранены.

### Непрерывность вращения и остаток топлива

При достаточном топливе двигатель не останавливается на границе 10-тикового
интервала. Остаток меньше полной цены интервала тоже используется: например,
6 Potentia при 128 RPM дают пропорциональное время работы вместо ожидания 8.
Дробный энергетический баланс сохраняется целыми числами; погрешность последнего
игрового тика учитывается в следующем платеже. Выбранная скорость сохраняется,
при недостаточной подаче топлива двигатель останавливается без автоснижения RPM.
На 128 RPM требуется 8 Potentia за 40 тиков (16 в секунду).

Внутренний запас двигателя — суммарно 256 единиц Potentia, включая ещё
неизрасходованное оплаченное топливо. Забор начинается сразу после установки:
каждый тик двигатель запрашивает максимум, доступный в подключённом источнике
и помещающийся в запас. При прямом подключении банка может опустеть за один тик;
при подключении через трубы скорость ограничена их пропускной способностью.
После замены банки забор возобновляется автоматически. По мере расходования
двигатель подкачивает недостающую эссенцию; запас сохраняется при загрузке мира.
Проверки NeoForge: 23/23 GameTest, включая непрерывность вращения, замену банок,
автопополнение, общий лимит запаса и сохранение дробного баланса после загрузки.

## Помпа для эссенции (0.5.0)

`thaumic_create:essentia_pump` ставится на входную грань приёмника во всех шести
направлениях. ПКМ по вентилю открывает/перекрывает передачу; положение вентиля
меняется в модели. Вращение Create не требуется. Предмет добавлен в творческую
вкладку аддона и в функциональные блоки.

Помпа читает запрос через общий API `EssentiaTransport`. При фактическом заборе
приёмником она передаёт одну единицу через штатный `takeFromAir` зеркала TR,
не чаще раза в 5 тиков. Предварительный просмотр источников не расходует эссенцию,
внутреннего буфера нет. Приёмники без конкретного аспекта видят доступные аспекты
по очереди и выбирают подходящий сами (например, центрифуга отвергает первичные).
Поддерживаются также приёмники аддонов, которые забирают эссенцию сами и объявляют
положительную тягу без `canInputFrom` — так устроен чинитель TT. Обычные и пустотные
банки (`EssenceJarContainer`) исключены как получатели.

Радиус поиска местного зеркала — 8 блоков; зеркала напротив всасывающей стороны
получают приоритет. Используются только загруженные чанки и действительные
двусторонние связи зеркал, включая межпространственные. Дальний конец забирает
эссенцию по обычным правилам TR (8 блоков перед зеркалом). Локальные банки напрямую
не опустошаются. Источник модели сохранён в `assets-src/essentia_pump.bbmodel`,
повторный экспорт: `python3 tools/export_essentia_pump.py`.

В книге Create зеркало полностью скрыто до завершения `mirroressentia`, затем
его копия автоматически открывается, аналогично «Искусству алхимии». От неё
наследуется исследование помпы с головоломкой сложности 2. Рецепт магического
верстака: `VAT / BPB / THV`, где V — клапан эссенции, A — магический алембик,
T — труба эссенции, B — магические меха, P — механическая помпа Create,
H — воронка. Стоимость: 10 Ordo, 10 Aqua, 10 Perditio.

Проверки помпы находятся в `MirrorPumpGameTests`. Для них дополнительно нужны
NeoForge JAR Thaumic Tinkerer и Thaumic New Horizons в `build/validation-mods`.
Они используются только при `-PverifyPress` и не входят в релизный JAR.
Визуальная проверка модели и книги в обычном игровом клиенте остаётся ручной.
